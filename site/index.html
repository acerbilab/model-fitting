Which tool do I need?

“I want the parameters that fit my data best.”

→ PyBADS

Maximum-likelihood and MAP fits, with up to about 20 parameters.

“I want the posterior over my parameters, and to compare models.”

→ PyVBMC

The posterior and the model evidence, best with up to about 10 parameters.

“I can simulate my model, but I can't write down its likelihood.”

→ PyIBS, then PyBADS or PyVBMC

For data with discrete responses.

The tools

Ready to use

Fit your model

PyBADS BADS in MATLAB

Bayesian Adaptive Direct Search: fast, robust optimization for maximum-likelihood and MAP fits when the objective is rough, noisy or slow to evaluate, with up to about 20 parameters.

pip install pybads

Docs Python MATLAB

Acerbi & Ma, NeurIPS 2017 · Singh & Acerbi, JOSS 2024

Get the posterior and the evidence

PyVBMC VBMC in MATLAB

Variational Bayesian Monte Carlo: an approximate posterior over your parameters and an estimate of the model evidence, for model comparison, from a small budget of likelihood evaluations, even noisy ones. Best with up to about 10 parameters.

pip install pyvbmc

Docs Python MATLAB A run in 3D

Acerbi, NeurIPS 2018 and NeurIPS 2020 · Huggins, Li, Tobaben, Aarnos & Acerbi, JOSS 2023

When you can only simulate

PyIBS IBS in MATLAB

Inverse binomial sampling: unbiased, efficient estimates of the log-likelihood of models you can simulate but not write down, for data with discrete responses. Pair it with PyBADS or PyVBMC, which are built to handle noisy estimates.

pip install pyibs

Python MATLAB

van Opheusden, Acerbi & Ma, PLOS Computational Biology 2020

Inference in a single forward pass

In active development

ACE and nanoACE

The Amortized Conditioning Engine: one transformer, trained on simulated data, that answers inference and prediction questions in a single forward pass and can take prior information at run time. It is research code in active development, and the start of our next generation of methods. nanoACE is a small, readable implementation with an in-browser playground.

Playground nanoACE ACE paper

Chang, Loka, Huang, Remes, Kaski & Acerbi, AISTATS 2025
